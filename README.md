# Detecteur_pic_wifi

Acquisition et analyse temps réel du RSSI Wi-Fi sur Raspberry Pi.

## Fonctionnalités

- Acquisition RSSI temps réel
- Détection des pics Wi-Fi
- Calcul de la puissance reçue
- Calcul de l'énergie reçue
- Calcul de la durée des événements
- Sauvegarde CSV
- Sauvegarde PNG
- Interface graphique Tkinter

## Matériel

- Raspberry Pi
- Interface Wi-Fi 2.4 GHz
